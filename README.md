# 🤖 多Agent圆桌 · 本地多智能体讨论工作台

让多个 AI Agent 围坐一桌，自动多轮讨论帮你解决问题。纯本地运行，数据全部存在本目录的 `data/` 文件夹里。

## 快速开始

1. 安装 [Node.js](https://nodejs.org)（≥ 18 版本）
2. **双击 `多Agent圆桌.lnk`**（桌面快捷方式，图标是侧栏那个小机器人；没有了就双击 `创建桌面快捷方式.cmd` 重新生成），或直接双击 `start.bat`
3. 浏览器自动打开 `http://localhost:8787`

前端入口在 **`首页/`** 文件夹：`首页/index.html` 是网页首页，`首页/app.js`、`首页/style.css`、`首页/starfield.js` 是配套的脚本与样式。它是本地服务渲染的页面，**必须由 `start.bat` 起服务后通过 `http://localhost:8787` 打开**；直接双击 `首页/index.html`（`file://`）打不开讨论功能，因为它需要请求本地 API。

## 桌面快捷方式 / 发给朋友

| 文件 | 作用 |
|---|---|
| `多Agent圆桌.lnk` | 桌面快捷方式本体，图标取自左侧栏那个头顶红点的黄色小机器人 |
| `logo.ico` | 快捷方式用的图标（16/24/32/48/64/128/256 多尺寸）；想重画就改 `tools/make-icon.py` 后跑 `python tools/make-icon.py` |
| `创建桌面快捷方式.cmd` | **换了电脑 / 换了文件夹位置 / 图标变成白纸时跑一次**：按当前路径重建 `.lnk` 并复制一份到桌面 |
| `打包分享包.cmd` | 生成 `多Agent圆桌-分享包.zip`：**清空所有 API Key**、删掉聊天历史与 `apikey.txt`，朋友解压就能用 |

> ⚠️ **别直接压缩整个文件夹发给别人**：`data/agents.json` 和 `apikey.txt` 里存着你的真实 API Key，会一起发出去。用 `打包分享包.cmd` 打出来的 zip 才是干净的。

朋友拿到 zip 后：装 Node.js → 解压 → 双击 `创建桌面快捷方式.cmd` 一次 → 双击桌面上的「多Agent圆桌」即可。

## 功能一览

| 模块 | 说明 |
|---|---|
| 🎭 身份卡片（左栏） | 点击卡片编辑：**角色称呼、供应商、API Key、模型名称、人设、思考程度**；供应商内置了接口地址（千问/DeepSeek/Kimi/智谱/OpenAI/本地 Ollama），界面上不出现 URL；没有头像、官网链接、代表色，也没有「参与讨论」勾选框——**加入的身份全部参加圆桌讨论，人人平等，不设主持人** |
| 🎮 Agent Quest 游戏化界面 | 奶油色糖果玩具风：角色头像、回合徽章、XP 等级、任务通关庆祝、按钮实体按压与非阻塞成就通知；支持可选游戏音效、手机抽屉侧栏和减少动态效果偏好，所有反馈均不冻结背景动画 |
| 📁 项目 / ✅ 任务 | 左栏折叠区，存在 `data/projects.json`、`data/tasks.json` |
| 🕘 历史会话 | 上下文自动保存到 `data/history/`（.json 全量 + .md 镜像可直接阅读） |
| 📎 添加文件/目录 | 输入框上方「添加文件/目录」，扫描后勾选文本/代码文件，内容随消息注入讨论上下文。上限：单文件 120KB、合计 500KB、最多 100 个文件（超长文件只读前 120KB） |
| 🧾 小队记忆 | 「冒险营地 → 小队记忆」维护一组长期背景（关于你、你的项目、偏好），开启注入后每位伙伴的 system prompt 都会带上，**对之后每一场讨论生效**，不分身份。存在 `data/memory.json` |
| 🎒 技能背包 | 把含 `SKILL.md` 的文件夹放进 `skills/`，点「重新扫描」即被识别；讨论时最多取 8 个技能注入上下文。同时会扫描 `~/.agents/skills`、`~/.claude/skills`、`~/.zcode/skills`；插件缓存里的技能只展示、不注入 |
| 🚀 多Agent联动 | 选 **自动（全体收敛即停）/ 2 / 4 / 6 / 8 / 10 轮次**；每轮所有身份依次发言、互相可见；自动模式下每位身份在发言末尾自评 `[收敛度] 0-10`，**全员 ≥8 才停**（无主持人，没人拥有裁判权）；最后一轮自动要求给出最终结论 |
| 🧠 思考程度 | 每个身份单独设置（关闭/低/中/高）；发送前也可临时统一覆盖。GLM 系列走 `thinking` 参数，OpenAI 兼容接口走 `reasoning_effort` |
| ⬇ 导出MD / 🧹 清空 | 顶栏一键导出 Markdown 聊天记录；一键清空当前对话；也可删除整个会话 |

## 数据目录结构

```
多agent/
├── 首页/            # 前端入口（网页首页 + app.js / style.css / starfield.js）
├── data/            # 数据目录（见下）
├── skills/          # 技能目录（放含 SKILL.md 的文件夹）
├── tools/           # 图标生成 / 快捷方式 / 打包脚本
├── server.js        # 本地服务（纯 Node.js，无依赖）
└── start.bat        # 启动入口
```

```
data/
├── agents.json      # 身份配置（含 API Key，仅存本地）
├── projects.json    # 项目列表
├── tasks.json       # 任务列表
├── memory.json      # 小队记忆（inject 开关 + items 数组）
├── settings.json    # 应用设置
└── history/         # 历史会话（<id>.json 完整上下文 / <id>.md 可读镜像）
```

身份字段只有：`name`（角色称呼）、`provider`（供应商）、`apiKey`、`model`、`thinking`（思考程度）、`persona`（人设）。接口地址由供应商自动推导，不存盘。

## 常见问题

- **身份弹窗里的下拉（供应商 / 思考程度 / 模型名称）**：全部是自制的液态玻璃弹层，不再用原生 `<select>` / `<datalist>`（原生弹层在深色主题下会出现白底浅字、看不见选项的问题）。若下拉点开是空的，就是页面没连上本地服务——看页面底部红色提示条，按 `start.bat` 启动后刷新。
- **端口 8787 被占用**：多半是已经有一个旧实例在跑，控制台会给出提示；换端口用 `set PORT=9000 && node server.js`。
- **改了供应商就报 401 / 模型不存在**：模型名和 API Key 都跟供应商绑定，切供应商时下拉会自动清空模型名并提示，记得重新拉取模型、填对应供应商的 Key。
- **某身份报「API错误 401」**：API Key 填错、未填，或与所选供应商不匹配（例如千问的 Key 填在了 DeepSeek 身份上）。
- **拉取模型失败**：检查 API Key 是否属于所选供应商；部分供应商的 Key 有地域/权限限制。
- **拉取模型列表已经清洗**：会自动过滤图像/语音/向量/重排/实时翻译类模型，只留对话模型（千问从 180+ 降到 130 左右）。
- **技能背包里看不到自己的技能**：确认文件夹里有 `SKILL.md`（文件名大小写要一致），位置在 `skills/` 下或用户级技能目录，然后点「重新扫描」；一次最多注入 8 个。
- **自动轮次停不下来**：自动模式要求所有身份收敛度自评 ≥8 才停，最多跑 10 轮；想固定长度就直接选「2/4/6/8/10 轮」。
- **自动模式花费比预期高**：每位身份每轮都会重新读完整个讨论历史，身份越多/轮次越多，token 消耗近似线性上升。
- **停止讨论**：发送后按钮会变为「⏹ 停止」，点击即中止，已完成的内容会保留。
