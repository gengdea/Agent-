# 🤖 多Agent圆桌 · 本地多智能体讨论工作台

让多个 AI Agent 围坐一桌，自动多轮讨论帮你解决问题。纯本地运行：服务只监听 `127.0.0.1`，数据全部存在本目录的 `data/` 文件夹里（已 gitignore，不会进入仓库）。

## 快速开始

1. 安装 [Node.js](https://nodejs.org)（≥ 18 版本）
2. **双击 `start.bat`**（或命令行 `npm start`），浏览器自动打开 `http://localhost:8787`
3. 想要桌面快捷方式：**双击 `创建桌面快捷方式.cmd` 一次**，桌面上会生成带小机器人图标的「多Agent圆桌」快捷方式，以后一键启动

> ⚠️ 前端是本地服务渲染的页面，**必须通过 `http://localhost:8787` 打开**；直接双击 `首页/index.html`（`file://`）连不上本地 API，讨论功能打不开。
>
> 换了电脑 / 换了文件夹位置 / 快捷方式图标变成白纸时，把 `创建桌面快捷方式.cmd` 再跑一次即可。

## 功能一览

| 模块 | 说明 |
|---|---|
| 🎭 身份卡片（左栏） | 点击卡片编辑：**角色称呼、供应商、API Key、模型名称、人设、思考程度**；供应商内置接口地址（千问/DeepSeek/Kimi/智谱/OpenAI/本地 Ollama），界面上不出现 URL；没有头像、官网链接、代表色，也没有「参与讨论」勾选框——**加入的身份全部参加圆桌讨论，人人平等，不设主持人** |
| 🕹️ 启动动画 | 糖果街机开机：PRESS START 待机 → 小队集结 → 自检盖章 → 蓄能 → READY 拉幕；音效为逐渐递增的合成音阶（浏览器要求一次点击手势后出声）；点击任意处跳过；遵循侧栏音效开关与系统「减少动态效果」偏好；地址加 `?bootHold=1` 可定格预览 |
| 🎮 Agent Quest 游戏化界面 | 奶油色糖果玩具风：角色头像、回合徽章、XP 等级、任务通关庆祝、按钮实体按压与非阻塞成就通知；支持可选游戏音效、手机抽屉侧栏，所有反馈均不冻结背景动画 |
| 📁 项目 / ✅ 任务 | 左栏折叠区，存在 `data/projects.json`、`data/tasks.json` |
| 🕘 历史会话 | 上下文自动保存到 `data/history/`（.json 全量 + .md 镜像可直接阅读） |
| 📎 添加文件/目录 | 输入框上方「添加文件/目录」，扫描后勾选文本/代码文件，内容随消息注入讨论上下文。上限：单文件 120KB、合计 500KB、最多 100 个文件（超长文件只读前 120KB） |
| 🧾 小队记忆 | 「冒险营地 → 小队记忆」维护一组长期背景（关于你、你的项目、偏好），开启注入后每位伙伴的 system prompt 都会带上，**对之后每一场讨论生效**，不分身份。存在 `data/memory.json` |
| 🎒 技能背包 | 把含 `SKILL.md` 的文件夹放进 `skills/`，点「重新扫描」即被识别；讨论时最多取 8 个技能注入上下文。同时会扫描 `~/.agents/skills`、`~/.claude/skills`、`~/.zcode/skills`；插件缓存里的技能只展示、不注入 |
| 🚀 多Agent联动 | 选 **自动（全体收敛即停）/ 2 / 4 / 6 / 8 / 10 轮次**；每轮所有身份依次发言、互相可见；自动模式下每位身份在发言末尾自评 `[收敛度] 0-10`，**全员 ≥8 才停**（无主持人，没人拥有裁判权）；最后一轮自动要求给出最终结论 |
| 🧠 思考程度 | 每个身份单独设置（关闭/低/中/高）；发送前也可临时统一覆盖。GLM 系列走 `thinking` 参数，OpenAI 兼容接口走 `reasoning_effort` |
| ⬇ 导出MD / 🧹 清空 | 顶栏一键导出 Markdown 聊天记录；一键清空当前对话；也可删除整个会话 |

## 目录结构

```
多agent/
├── 首页/                  # 前端入口（index.html + app.js / style.css / starfield.js / boot.js 启动动画）
├── data/                  # 本地数据（身份配置、会话历史、记忆、项目任务）——已 gitignore，不入库
├── skills/                # 技能目录（放含 SKILL.md 的文件夹）
├── test/                  # 端到端测试（e2e.js + mock-upstream.js 模拟上游）
├── tools/                 # create-shortcut.ps1 快捷方式生成 / make-icon.py 图标生成
├── server.js              # 本地服务（纯 Node.js，零依赖；仅监听 127.0.0.1）
├── start.bat              # 启动入口
├── 创建桌面快捷方式.cmd    # 生成 / 修复桌面快捷方式（唯一快捷方式启动链）
├── 三人格顾问-合集.md      # 内置三位顾问的完整人设
└── logo.ico               # 快捷方式图标（多尺寸）
```

## 内置身份（首次启动的默认小队）

| 身份 | 风格 | 默认供应商 | 默认模型 |
|---|---|---|---|
| 陆灼 | 鼓励型：先承认情绪，再给 24 小时内能做完的最小动作 | 千问 | `qwen3.8-max` |
| 周衡 | 中立型：事实/假设/情绪分栏 + 选项对照表 + 条件式建议 | DeepSeek | `deepseek-v4-pro` |
| 林冽 | 对立型：三条致命假设 + 动机那一刀 + 生路条件 | Kimi | `kimi-k3.1-pro` |

三份顾问的完整人设见 `三人格顾问-合集.md`。以上只是首次初始化时的默认值，之后在身份卡片里改什么就是什么。

## 数据与隐私

- **所有数据只存本地**：`data/`（身份配置含 API Key、聊天历史、小队记忆）与 `apikey.txt` 均在 `.gitignore` 中，不会进入 Git 仓库；分发请让对方直接 clone / 下载仓库后按「快速开始」操作
- **服务只监听 `127.0.0.1`**，并校验 Host 头，局域网其他设备与网页跨站请求均无法访问
- 想重画图标：改 `tools/make-icon.py` 后运行 `python tools/make-icon.py`

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「端口 8787 已被占用」 | 关掉旧的 node 进程（任务管理器搜 node）后重新启动 |
| 页面报「初始化失败 / 拉取失败」 | 旧实例还在用旧代码服务，同上关掉重开 |
| 双击 `首页/index.html` 没反应 | 请通过 `http://localhost:8787` 访问，见「快速开始」 |
| 快捷方式图标变白纸 | 双击 `创建桌面快捷方式.cmd` 重新生成 |
